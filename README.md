# AI智能存钱记账助手

一个纯前端、无广告、无登录的AI智能记账助手，帮助你管理个人财务、设定存钱目标、智能分析消费习惯。

## 功能特点

- 📊 **智能记账**：AI自动识别分类，支持语音输入
- 💰 **资金桶管理**：12种理财法则，智能分配资金
- 🎯 **存钱目标**：设定目标，关联资金桶，自动追踪进度
- 📈 **数据分析**：支出饼图、收支趋势、智能建议
- 🛒 **预算预购**：虚拟预购清单，真实购买核销
- 🦞 **龙虾智能体**：自然语言记账，智能查询
- 🌙 **暗色模式**：支持亮色/暗色主题切换
- 📱 **移动端适配**：完美适配手机和电脑

## 使用方法

直接打开 `index.html` 即可使用，所有数据保存在浏览器本地存储中。

## 部署

本项目可以部署到任意静态网站托管服务，如 GitHub Pages、Netlify、Vercel 等。

### GitHub Pages 部署

1. Fork 或克隆本仓库
2. 在仓库设置中启用 GitHub Pages
3. 选择 `main` 分支作为源

## 技术栈

- 纯 HTML + CSS + JavaScript（单文件）
- Font Awesome 6.5.1（图标）
- Chart.js 4.4.1（图表）
- LocalStorage（数据存储）
